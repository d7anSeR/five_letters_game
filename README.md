# 5 букв

Консольная игра в духе Wordle. Загадывается слово из 5 русских букв,
у игрока 6 попыток. После каждой попытки игрок видит подсказку по буквам:

- ✅ — буква на своём месте;
- 🟡 — буква есть в ответе, но не на этом месте;
- ❌ — буквы нет в ответе (или её вхождение уже израсходовано).

## Статус проекта

- [x] **MR1** — словарь, детерминированный выбор слова, модель сессии
- [x] **MR2** — правила, валидация, ✅/🟡/❌, WIN/LOSE
- [x] **MR3** — консольный интерфейс и детерминированный режим

## Модуль MR1. Данные и сессия

### Словарь

- `Dictionary` — неизменяемый словарь (≥50 слов по 5 русских букв).
  В конструкторе валидирует длину, алфавит и непустоту; приводит слова
  к нижнему регистру и схлопывает дубликаты.
- `DictionaryLoader` — загрузка словаря из classpath (`/dictionary.txt`).
  Файл в UTF-8, пустые строки и строки-комментарии (`#`) пропускаются.

### Детерминированный выбор слова

- `GameFactory.startGame(dictionary, maxAttempts, seed) -> GameSession` —
  создаёт партию. Выбор слова детерминирован: одинаковый `seed` и один
  и тот же словарь всегда дают одинаковое загаданное слово. Это делает
  игру воспроизводимой и тестируемой.

### Модель партии

- `GameSession` — состояние одной игры:
    - `answer` — загаданное слово;
    - `maxAttempts` — лимит попыток;
    - `attemptsUsed` — сколько попыток уже сделано;
    - `attemptsHistory` — история сделанных попыток (только для чтения);
    - `status` — текущий статус партии.

  Инварианты:
    - ответ ровно из 5 букв;
    - `maxAttempts > 0`;
    - завершённая партия не принимает новые попытки и не меняет статус.

- `GameStatus` — перечисление статусов: `IN_PROGRESS`, `WIN`, `LOSE`.

## Модуль MR2. Правила игры

### Точка входа

- `GameRules.applyGuess(session, dictionary, guess) -> GuessResult` —
  главная операция хода. Валидирует ввод, считает подсказки по буквам,
  регистрирует попытку и при необходимости переводит партию в `WIN`/`LOSE`.
  Логика не зависит от консольного ввода-вывода.

### Валидация ввода

- `GuessValidator` — проверяет:
    - ввод не `null`;
    - после приведения к нижнему регистру и `trim()` — ровно 5 символов;
    - все символы — кириллица;
    - слово есть в словаре.

- `InvalidGuessException` — некорректный ввод. Бросается **до** изменения
  состояния сессии, поэтому опечатка не тратит попытку и не попадает
  в историю.

### Раскраска букв

- `LetterResult` — метка одной буквы:
    - `CORRECT` (✅) — буква на своём месте;
    - `PRESENT` (🟡) — буква есть в ответе, но не на этом месте;
    - `ABSENT` (❌) — буквы нет в ответе (или её вхождение уже израсходовано).

- `GuessResult` — результат попытки: нормализованное слово, список
  из пяти меток, статус партии после хода. Список меток неизменяемый,
  конструктор копирует входной список.

### Финалы партии

- **WIN** — если введённое слово полностью совпало с ответом.
- **LOSE** — если попытки закончились (`attemptsUsed >= maxAttempts`),
  а слово не угадано. Ответ остаётся доступен через `session.answer()`,
  чтобы интерфейс мог его показать.
- После `WIN`/`LOSE` любые новые попытки отклоняются с
  `IllegalStateException`.

### Что проверяет MR2

- Валидация: длина, не-буквы, слово вне словаря, регистр — попытка
  не тратится.
- Раскраска: базовый кейс, полное совпадение, отсутствие совпадений,
  повторяющиеся буквы.
- Финалы: `WIN` при угадывании, `LOSE` после `maxAttempts`,
  показ ответа при поражении, отказ от новых попыток.
- Логика полностью отделена от консольного ввода-вывода.


## Модуль MR3. Интерфейс и проверяемость

### Меню

- `Menu` — интерактивное меню: «новая игра» / «выход». Вся игровая логика
  делегируется в `GameRules`.
- Некорректный пункт меню (не `1` и не `2`) не роняет программу:
  печатается подсказка и меню показывается снова.
- После завершения партии управление возвращается в меню, поэтому
  можно сыграть несколько игр подряд без перезапуска программы.
- Некорректный ввод в игре (`InvalidGuessException`) перехватывается
  и печатается как сообщение об ошибке; попытка при этом не тратится.
- Выход — только через пункт `2`.

### Формат вывода

- `ConsoleView` — форматирование результата в строки. Отделено от
  ввода-вывода: класс не знает, куда пишется результат, — возвращает
  готовые строки.

### Фиксированный формат:

❌🟡❌❌🟡 арбуз

Осталось попыток: 5

Победа! Слово угадано за 4 попытки

Неудача. Загаданное слово: озеро

- `formatGuess(GuessResult)` — метки + слово;
- `formatAttemptsLeft(GameSession)` — сколько попыток осталось;
- `formatWin(GameSession)` — победа с числом попыток;
- `formatLose(GameSession)` — поражение с показом ответа.

### Детерминированный режим для автопроверки

`Main` поддерживает три режима запуска. Достаточно любого из них,
но реализованы все три:
1. **Интерактивное меню** — без аргументов:

```bash
./gradlew run
```
   
2. **Одна игра с фиксированным seed** — для проверки
воспроизводимости:
```bash
./gradlew run --args="--seed 42"
```
```bash
Загадано: кредо
Попыток: 6
```

3. **Детерминированная проверка check** — для автопроверки раскраски и финалов:
```bash
./gradlew run --args="check --answer озеро --guess арбуз"
```

```bash
❌🟡❌❌🟡 арбуз
Осталось попыток: 5
```

### Что проверяет MR3

- Меню: некорректный пункт не роняет программу; несколько партий
подряд без перезапуска. 
- Формат вывода: совпадает с заданием, включая порядок строк. 
- Детерминированный режим: check даёт предсказуемый вывод; --seed воспроизводим. 
- Логика интерфейса отделена от игровой логики: Menu знает только про ввод-вывод, GameRules — только про правила.


## Бонусы

### Уровни сложности

- `Difficulty` — три уровня: `EASY` (8 попыток), `NORMAL` (6), `HARD` (4).
- `GameFactory.startGame(dictionary, difficulty, seed)` — перегрузка, старая сигнатура с `int maxAttempts` не тронута.
- В меню пункт «3 — сложность», текущий уровень показывается в заголовке.

### Цветной вывод

- ANSI-цвета для ✅ / 🟡 / ❌: зелёный, жёлтый, красный.
- `ConsoleView.setColorEnabled(boolean)` — ручное управление.
- `ConsoleView.autoDetectColor()` — включает цвет, только если stdout —
  настоящий терминал (`System.console() != null`) и нет переменной
  окружения `NO_COLOR`.
- В детерминированном режиме (`check`, `--seed`, `replay`) цвет выключен,
  поэтому автопроверка видит чистый текст.

### Статистика сессии

- `SessionStats` — счётчики за один запуск программы:
  `gamesPlayed`, `wins`, `losses`, `totalAttempts`, `bestAttempts`,
  `averageAttempts()`.
- `record(GameSession)` игнорирует незавершённые партии.
- `Menu` вызывает `record` после каждой завершённой игры.
- В меню пункт «4 — статистика».

### Replay по seed и попыткам

- Команда `replay --seed N <guess1> <guess2> ...`:
    - восстанавливает партию по seed;
    - последовательно применяет попытки;
    - печатает результат каждой попытки;
    - останавливается на `WIN`/`LOSE`.
- Вывод детерминирован: одинаковые аргументы → одинаковый вывод.
- Некорректные слова не роняют программу — печатается «Пропуск ...».

### Категории слов

- Три категории: `животные`, `еда`, `природа`.
- Файлы: `dictionary.animals.txt`, `dictionary.food.txt`,
  `dictionary.nature.txt` в `src/main/resources/`.
- В меню пункт «5 — категория».

### Подсказки к словам

- Формат словаря: `слово|подсказка`.
- Для основного словаря подсказки лежат отдельно в
  `dictionary.hints.txt` — `TemplateSmokeTest` читает `dictionary.txt`
  напрямую и ждёт чистые слова без `|`.
- Для категорий подсказки пишутся прямо в файле: `мышка|маленький грызун`.
- `Dictionary.hint(word)` возвращает подсказку или `null`,
  `hasHint(word)` — `boolean`.
- В игре, если у загаданного слова есть подсказка, печатается
  `Можно ввести '?' для подсказки.`, по `?` показывается текст
  или `Подсказки нет.`.
- Подсказка не тратит попытку.

## Тесты

Обязательные тесты в `src/test/java/academy/fiveletters/mandatory/`:

- `mandatory/mr1/` — словарь, seed, модель сессии.
- `mandatory/mr2/` — валидация, раскраска, финалы.
- `mandatory/mr3/` — меню, детерминированный режим.

Бонусные тесты в `src/test/java/academy/fiveletters/bonus/`:

- `DifficultyTest` — попытки по уровням, LOSE после HARD.
- `ColorTest` — ANSI вкл/выкл.
- `SessionStatsTest` — пустая статистика, накопление, IN_PROGRESS.
- `ReplayTest` — детерминированность replay.
- `CategoriesTest` — три категории, ≥10 слов по 5 букв, не совпадают.
- `HintTest` — `hint`/`hasHint`, регистр, загрузка из ресурсов.
