# 5 букв

Консольная игра в духе Wordle. Загадывается слово из 5 русских букв,
у игрока 6 попыток.

## Статус проекта

- [x] **MR1** — словарь, детерминированный выбор слова, модель сессии
- [ ] **MR2** — правила, валидация, ✅/🟡/❌, WIN/LOSE
- [ ] **MR3** — консольный интерфейс и детерминированный режим

## Модуль MR1

- `Dictionary` - неизменяемый словарь (≥50 слов по 5 русских букв).
- `DictionaryLoader` - загрузка словаря из classpath (`/dictionary.txt`).
- `GameFactory.startGame(dictionary, maxAttempts, seed)` — создаёт партию;
  одинаковый `seed` + словарь дают одинаковое слово.
- `GameSession` - модель партии: `answer`, `maxAttempts`, `attemptsUsed`,
  `attemptsHistory`, `status`. Инварианты: ответ ровно из 5 букв,
  `maxAttempts > 0`, завершённая партия не принимает попытки.
- `GameStatus` - перечисление статусов игры.
