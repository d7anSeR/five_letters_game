# 5 букв

Консольная игра в духе Wordle. Загадывается слово из 5 русских букв,
у игрока 6 попыток. После каждой попытки игрок видит подсказку по буквам:

- ✅ — буква на своём месте;
- 🟡 — буква есть в ответе, но не на этом месте;
- ❌ — буквы нет в ответе (или её вхождение уже израсходовано).

## Статус проекта

- [x] **MR1** — словарь, детерминированный выбор слова, модель сессии
- [x] **MR2** — правила, валидация, ✅/🟡/❌, WIN/LOSE
- [ ] **MR3** — консольный интерфейс и детерминированный режим

## Модуль MR1. Данные и сессия

### Словарь

- `Dictionary` — неизменяемый словарь (≥50 слов по 5 русских букв).
  В конструкторе валидирует длину, алфавит и непустоту; приводит слова
  к нижнему регистру и схлопывает дубликаты.
- `DictionaryLoader` — загрузка словаря из classpath (`/dictionary.txt`).
  Файл в UTF-8, пустые строки и строки-комментарии (`#`) пропускаются.

### Детерминированный выбор слова

- `GameFactory.startGame(dictionary, maxAttempts, seed) -> GameSession` —
  создаёт партию. Выбор слова детерминирован: одинаковый `seed` и один
  и тот же словарь всегда дают одинаковое загаданное слово. Это делает
  игру воспроизводимой и тестируемой.

### Модель партии

- `GameSession` — состояние одной игры:
    - `answer` — загаданное слово;
    - `maxAttempts` — лимит попыток;
    - `attemptsUsed` — сколько попыток уже сделано;
    - `attemptsHistory` — история сделанных попыток (только для чтения);
    - `status` — текущий статус партии.

  Инварианты:
    - ответ ровно из 5 букв;
    - `maxAttempts > 0`;
    - завершённая партия не принимает новые попытки и не меняет статус.

- `GameStatus` — перечисление статусов: `IN_PROGRESS`, `WIN`, `LOSE`.

## Модуль MR2. Правила игры

### Точка входа

- `GameRules.applyGuess(session, dictionary, guess) -> GuessResult` —
  главная операция хода. Валидирует ввод, считает подсказки по буквам,
  регистрирует попытку и при необходимости переводит партию в `WIN`/`LOSE`.
  Логика не зависит от консольного ввода-вывода.

### Валидация ввода

- `GuessValidator` — проверяет:
    - ввод не `null`;
    - после приведения к нижнему регистру и `trim()` — ровно 5 символов;
    - все символы — кириллица;
    - слово есть в словаре.

- `InvalidGuessException` — некорректный ввод. Бросается **до** изменения
  состояния сессии, поэтому опечатка не тратит попытку и не попадает
  в историю.

### Раскраска букв

- `LetterResult` — метка одной буквы:
    - `CORRECT` (✅) — буква на своём месте;
    - `PRESENT` (🟡) — буква есть в ответе, но не на этом месте;
    - `ABSENT` (❌) — буквы нет в ответе (или её вхождение уже израсходовано).

- `GuessResult` — результат попытки: нормализованное слово, список
  из пяти меток, статус партии после хода. Список меток неизменяемый,
  конструктор копирует входной список.

### Финалы партии

- **WIN** — если введённое слово полностью совпало с ответом.
- **LOSE** — если попытки закончились (`attemptsUsed >= maxAttempts`),
  а слово не угадано. Ответ остаётся доступен через `session.answer()`,
  чтобы интерфейс мог его показать.
- После `WIN`/`LOSE` любые новые попытки отклоняются с
  `IllegalStateException`.

### Что проверяет MR2

- Валидация: длина, не-буквы, слово вне словаря, регистр — попытка
  не тратится.
- Раскраска: базовый кейс, полное совпадение, отсутствие совпадений,
  повторяющиеся буквы.
- Финалы: `WIN` при угадывании, `LOSE` после `maxAttempts`,
  показ ответа при поражении, отказ от новых попыток.
- Логика полностью отделена от консольного ввода-вывода.
